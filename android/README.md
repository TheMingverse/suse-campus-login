# SUSE 校园网 · Android

支持 Android 10 及以上手机和平板，适配已确认的 `SUSE`、`SUSE_Hostel` 校园 Wi-Fi。

## 首次配置

1. 连接校园 Wi-Fi，打开应用，允许精确位置权限并开启系统定位，以识别 Wi-Fi 名称。
2. 填写账号密码，点击“只读刷新上网服务”，选择学校返回的运营商并保存。
3. 点击“立即检查并登录”。以后打开应用会自动检查校园网并按需登录，可在账号设置中关闭。

密码加密保存在本设备。暂时无法获取服务列表时可以先保存账号草稿。密码错误后需检查配置并重新保存，才会解除自动提交暂停。

## 桌面小组件

首页“桌面与快捷入口”可请求添加 **1×1** 或 **2×1** 小组件。点击后会请求系统展示添加确认页，实际是否弹出由手机桌面决定；系统确认添加后，App 才显示“已添加到桌面”。

若没有出现确认框，可点“重新请求 1×1／2×1”；也可点“返回桌面”，长按桌面空白处 → 添加小组件 → SUSE 登录。取消系统确认不会自动重试，App 会保留等待提示。

点击小组件会直接打开简洁认证页，检查校园 Wi-Fi 并按需登录，无需再次输入密码或点击登录按钮。未配置账号时会提示进入配置。成功后更新桌面结果并自动关闭；失败时保留原因和处理入口。

2×1 小组件显示“上次检查”和时间，代表历史结果，不是实时联网状态。具体占格由手机或平板桌面的网格决定。

## 控制中心磁贴

在首页点击“添加快捷设置磁贴”，或下拉控制中心，点击编辑，将“SUSE 登录”拖入快捷区域。点击磁贴启动同一认证流程；锁屏时需要先解锁。

## 任务何时结束

认证结束后不继续检测。按 Home、返回退出认证页或锁屏，应用完全离开前台时会取消本次任务；屏幕旋转不会重新提交。

本版本不含定时检测或连接 Wi-Fi 后后台自动登录。

## 应用内更新

新安装默认使用 GitHub。打开或重新回到 App 首页时会检查新版，发现后弹出“查看更新／稍后”提示；登录或编辑账号时会延后提示。可在“更新设置与关于”中关闭“打开 App 时检查更新”，也可随时手动检查。

本次先提供 GitHub 渠道，Gitee 默认镜像尚未启用。页面保留“自动选择”“Gitee 国内镜像”和“GitHub 官方渠道”；已保存的渠道设置会保留。自动选择在未配置 Gitee 时使用 GitHub，手动渠道不会自动切换。

发现新版本后可查看日志、大小和实际来源，确认后下载。下载可取消；完成哈希、包名、版本和正式签名身份检查后，才可点击安装。首次安装更新时，按页面提示进入系统授权，再由 Android 安装器确认。

离开前台会取消首页检查，离开更新页面会取消下载，不在后台常驻。Gitee 镜像地址由维护者提供，可在更新设置中填写；不要填写校园网账号或密码。

旧正式 0.3.0 没有更新入口，需要先手动覆盖安装首个带更新功能的正式版；之后可在 App 内发现后续新版。

构建和验证见[Android 开发文档](../docs/android-development.md)。正式发行维护见[签名与迁移指南](../docs/android-signing.md)。
