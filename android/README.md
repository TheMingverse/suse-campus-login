# SUSE 校园网 · Android

支持 Android 10 及以上手机和平板，适配四川轻化工大学宜宾校区的 `SUSE`、`SUSE_Hostel` 校园 Wi-Fi。

**[下载 Android 0.4.2](https://github.com/TheMingverse/suse-campus-login/releases/download/android-v0.4.2/SUSE-CampusLogin-Android-v0.4.2-release.apk)** · [更新说明](../docs/releases/android-v0.4.2.md)

## 首次配置

1. 连接尚未登录认证的校园 Wi-Fi，打开应用，按图文教程配置。
2. 填写校园网账号和密码，点击“只读刷新上网服务”，选择自己的上网服务，点击“保存设置”。
3. 点击“立即检查并登录”。按提示允许精确位置权限，并开启系统定位，以识别校园 Wi-Fi。

已经能上网时，可能无法刷新上网服务。可先保存账号草稿，等下次需要认证时补全。密码加密保存在本设备。

首次打开会展示教程，关闭或完成后不再自动弹出；需要时可点击首页顶部的“使用教程”重看。教程离线可读，图片可点开放大。

## 快捷登录

建议在系统设置中开启校园 Wi-Fi 的“自动连接”，搭配快捷入口使用。

- **控制中心磁贴**：在首页“桌面与快捷入口”中点击“添加快捷设置磁贴”，按提示添加“SUSE 登录”。
- **桌面小组件**：在同一区域点击“添加 1×1 小组件”或“添加 2×1 小组件”，按系统提示放到桌面。没有弹出时，可长按桌面空白处 → 添加小组件 → SUSE 校园网。

连接校园 Wi-Fi 后，点击磁贴或小组件即可检查并按需登录。小组件显示上次检查结果。教程内提供手动添加图解。

打开应用时也会自动检查并按需登录，可在账号设置中关闭。

## 应用内更新

新安装默认使用 GitHub。打开或回到 App 首页时会检查新版，发现后点击“查看更新”，确认下载并按提示安装。可在“更新设置与关于”中关闭自动检查，也可随时手动检查。

首次安装更新时，请按系统提示允许本应用安装更新。已有正式版直接覆盖安装，保留配置。旧正式 0.3.0 需要先手动下载新版。

Gitee 镜像暂未启用，建议使用 GitHub 渠道；已有渠道设置会保留。
