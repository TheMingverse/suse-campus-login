校园网自动登录 · Windows 1.1.3

支持：宿舍网线（包括 USB 转网口）、SUSE_Hostel 和 SUSE。
网线优先；已经能上网时跳过认证，短时间重连也一样。
真实有线认证仍需要现场验证，不把页面相同当成已经验证成功。

原来用 1.0 / 1.1.0 / 1.1.1 / 1.1.2 的同学：
1. 右下角旧程序图标 → 退出程序（只关窗口不算）。
2. 把新版完整解压到固定文件夹，保留旧版便于回退。
3. 双击新版 CampusLogin.exe，确认底部版本为 1.1.3。
4. 原账号密码会自动加载；勾选开机自动运行，点一次“保存并测试”更新开机启动位置。

首次使用：
1. 完整解压后双击 CampusLogin.exe，无需 Python 或管理员权限。
2. 填自己的校园网账号密码，选择运营商。
3. 默认勾选开机自动运行，点击“保存并测试”后生效。
4. 以后只需插网线或连接校园 Wi-Fi，并让程序保持运行。

详细步骤和界面图片：使用说明.html；升级与回退：升级说明.txt。
关闭窗口后还在右下角运行；完全停止请选“退出程序”。
有线参数不兼容时：点“连接诊断”→复制结果给维护者，先用官方页面登录。
不要发送账号密码、settings.json 或包含设备参数的长网址。
每个同学填自己的账号，本分享包不包含个人设置。

仅适用于 Windows 10/11 64 位，不是手机安装包。

1.1.1 改进：一个异常无线接口不会影响其他正常校园 Wi-Fi；多个连接分别检测。
连接诊断会区分“部分无线接口暂时无法读取”和“无线连接信息均无法读取”。

1.1.2 新增系统通知：登录并确认联网后提醒；启动已在线提醒一次。
认证未通过或需手动处理时提醒，同一故障不重复打扰，日常检查和短暂超时不弹通知。
默认开启；取消“显示系统通知”并点“保存并测试”即可关闭，重启后仍保持关闭。
通知是否显示、显示多久及声音由 Windows 设置决定；程序不会修改系统通知设置。

1.1.3 新增实时服务列表：发现学校认证要求时自动读取，也可点“刷新服务列表”。
刷新只读信息，不登录；暂停时也能刷新，不解除账号错误保护。
学校改名后请从最新列表选择并保存，不会自动猜选或跳到第一项。
已经在线时可能暂时无法更新列表，保留原选择即可，不必退出账号或断网。
选择的新服务重启后保留；回退旧版可能需要重新选择旧版支持的运营商。
