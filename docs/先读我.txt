校园网自动登录 · Windows 1.1.3

适用：四川轻化工大学宜宾校区，Windows 10/11 64 位。
支持校园网线、SUSE_Hostel 和 SUSE。

第一次使用：
1. 将压缩包完整解压到固定文件夹，双击 CampusLogin.exe。
2. 插好校园网线或连接校园 Wi-Fi，填写自己的账号密码，选择上网服务。
3. 点击“保存并测试”。以后保持程序运行，需要登录时会自动处理。

密码由 Windows 在本机保护。

日常操作：
关闭窗口后，程序仍在右下角托盘运行；右键小图标可打开设置或退出。
勾选“开机自动运行”并保存后，下次登录 Windows 时会自动启动。
更换上网服务时，点击“刷新服务列表”，选择后保存。

升级：
先从托盘退出旧程序，再打开新版。原设置沿用。
使用开机启动的同学，请在新版保存一次，更新启动位置。

遇到问题：
点击“连接诊断”，复制报告，附上校区、Windows 版本、连接方式和窗口提示：
