## 中文

适用：Windows 10/11 64 位，四川轻化工大学宜宾校区宿舍网线、`SUSE_Hostel` 和 `SUSE`。非学校官方客户端。

### 本次改进

- 使用学校实时服务列表；窗口增加“刷新服务列表”，只读取选项，不提交账号密码，暂停期间也可使用。
- 原服务名称有效时继续自动登录；学校改名后请重新选择并保存，不按关键词猜选、不自动选第一项。
- 保存的新名称重启后保留；冲突、隐藏或需要额外信息的服务不自动使用。
- 切换网络或设置后旧结果失效；保留网线优先、多网卡隔离、通知去重和账号保护。

### 下载和升级

在本版本的 **Assets（资源）** 下载 `SUSE-CampusLogin-Windows-v1.1.3.zip`，完整解压后运行 `CampusLogin.exe`；不要误选自动生成的 Source code 源码包。

升级前退出旧托盘程序，新版放在固定文件夹运行。原设置沿用；如需开机启动，请在新版自行点击“保存并测试”更新路径。旧版文件保留在本机。回退旧版时，新服务名称可能无法读取，需要重新选择旧版支持的服务。

程序界面及 ZIP 内原有说明为中文；GitHub 首页提供[中文](../../README.md)与[English](../../README.en.md)两版阅读说明，默认中文。此次上传不修改既有程序与 ZIP。

135 项自动测试及五个合成界面场景通过；ZIP 完整性、AMD64 架构、校验值与隔离启动检查通过。真实新名称认证、宿舍网线、教室与其他电脑仍需现场验收，模拟测试不代表这些场景全部实测成功。

本包不含个人设置或日志。每人填写自己的账号，密码由 Windows 在本机保护；不要分享个人设置目录或密码。详细说明见[验证记录](../验证记录.md)。

## English

For 64-bit Windows 10/11, dormitory Ethernet and the `SUSE_Hostel` / `SUSE` Wi-Fi networks at the Yibin campus of Sichuan University of Science & Engineering. This is an unofficial client.

### Changes

- Reads live campus service lists. **刷新服务列表 (Refresh service list)** only reads options and never submits credentials; it also works while automatic login is paused.
- An existing exact match continues to work. Renamed services require you to select and save again; no keyword guessing or automatic first-option selection.
- New names survive restarts. Conflicting, hidden or extra-information services are not used automatically.
- Connection and settings changes invalidate stale results. Wired priority, per-adapter isolation, notification suppression and credential-error protection are retained.

### Download and upgrade

Under **Assets**, download `SUSE-CampusLogin-Windows-v1.1.3.zip`, extract the complete archive, and run `CampusLogin.exe`. The automatically generated “Source code” archives are development files, not the ready-to-run application.

Exit the old tray application before upgrading and keep the new folder in a permanent location. Existing settings are retained. If you use startup, click **保存并测试 (Save and test)** in the new application to update its startup path. Historical packages remain local. Downgrading may require choosing a service supported by the older version.

The application interface and original ZIP instructions are Chinese. The GitHub reading guides offer [中文](../../README.md) and [English](../../README.en.md), with Chinese as the default homepage. This publication does not change the existing executable or ZIP.

### Verification and privacy

135 automated tests and five synthetic UI scenarios passed. ZIP integrity, AMD64 architecture, checksums and isolated startup passed. Real renamed-service authentication, dormitory Ethernet, classroom networks and other PCs still need field verification; synthetic tests do not establish success in all those environments.

No personal settings or logs are included. Each user enters their own account, and Windows protects the locally saved password. Do not share passwords or your settings directory. See the [verification record — Chinese](../验证记录.md).
