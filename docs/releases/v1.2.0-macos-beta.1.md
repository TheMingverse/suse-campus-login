# Mac 测试版 · v1.2.0-macos-beta.1

适用：宜宾校区，macOS 15 及以上。

- 原生设置窗口与菜单栏，支持校园 Wi-Fi、网线和后台自动登录。
- 实时服务列表、Mac 钥匙串保存密码、登录时启动及系统通知。
- Apple 芯片下载 `arm64.dmg`，Intel 下载 `x86_64.dmg`；也提供 ZIP。

打开 DMG，将应用拖入“应用程序”，填写自己的账号、选择服务后保存。识别校园 Wi-Fi 时，请允许定位服务。首次打开若被系统阻止，到“系统设置 → 隐私与安全性”查看并确认。

这是通过 GitHub Mac 环境测试的版本，尚未在校内 Mac 上验证真实登录。应用采用临时签名，未进行 Apple 公证。

[使用说明](https://github.com/TheMingverse/suse-campus-login/blob/main/docs/macos.md) · [反馈问题](https://github.com/TheMingverse/suse-campus-login/issues)

---

For macOS 15 or later at the Yibin campus. Download `arm64` for Apple Silicon or `x86_64` for Intel. Open the DMG, drag the app to Applications, then enter your account and select a service. Allow Location Services for campus Wi-Fi identification. The interface is in Chinese.

This beta is tested on GitHub-hosted Macs; campus login on a physical Mac is not yet verified. The app is ad-hoc signed and has not been notarized by Apple.

SHA256 checksums and dependency lists are included with the downloads.
