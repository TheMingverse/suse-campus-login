# Android 0.4.1 使用教程实现记录

本文保留 0.4.1 教程开发阶段的记录。教程现已随 [Android 0.4.2](releases/android-v0.4.2.md) 一起发行。

## 版本与范围

目标版本为 0.4.1 / versionCode 6，包名及正式签名身份不变。本轮仅开发和本地验证，未正式签名、提交、推送或公开发布。已发布的 0.4.0 四文件及旧 0.3.0 发行目录保留原样。

教程为 6 页主流程、1 页磁贴手动图解和 5 页小组件手动图解。首次加入教程后，新安装与已有配置的升级用户均自动展示一次；明确关闭后不再自动展示，版本升级不会重置已读状态。首页顶部固定保留“使用教程”入口。

## 主教程文案

1. **首次配置前，先看这里**
   - 首次配置时，请连接尚未登录认证的校园 Wi-Fi。
   - 如果校园网已经登录、可以正常上网，可能无法刷新上网服务、完成运营商配置。可以先保存账号草稿，等下次需要登录认证时再补全。
   - 记得在系统 Wi-Fi 设置中开启校园 Wi-Fi 的“自动连接”，搭配后面的“SUSE 登录”磁贴，使用会更方便。
2. **填写你的校园网账号**
   - 连接 SUSE 或 SUSE_Hostel，填写自己的校园网账号和密码。
   - 操作时按提示允许精确位置权限，并开启系统定位，以识别校园 Wi-Fi。密码仅加密保存在此设备。
3. **选择运营商，保存并登录**
   - 点击“只读刷新上网服务”，再从“上网服务”中选择自己使用的服务。
   - 点击“保存设置”，最后点击“立即检查并登录”。
   - 暂时无法刷新时，可先“保存加密草稿”，以后再补全服务。
4. **推荐：添加登录磁贴**
   - 在首页“桌面与快捷入口”中，点击“添加快捷设置磁贴”，按系统提示添加“SUSE 登录”。
   - 以后连接校园 Wi-Fi 后，下拉控制中心，点一下它，就能检查并按需登录。
5. **也可以添加桌面小组件**
   - 在首页选择“添加 1×1 小组件”或“添加 2×1 小组件”，按系统提示放到桌面。
   - 以后点击小组件即可检查并按需登录。小组件显示的是上次检查结果。
6. **感谢使用**
   - 感谢使用 SUSE 校园网！希望它能让你连接校园网更省心。
   - 如果觉得好用，欢迎到 GitHub 为项目点一颗 Star，感谢你的支持。
   - 显示项目地址 `https://github.com/TheMingverse/suse-campus-login`，提供“前往 GitHub 点 Star”和“开始使用”按钮。

文案按维护者指定的 `public-copy-concise` 技能编排。页面文字、图示及阅读顺序集中在 `tutorial/TutorialContent.kt`，页面排版与本地状态分别由独立组件负责。

## 状态与界面行为

- 独立 SharedPreferences `usage_tutorial` 只保存 `dismissed` 布尔值，不包含账号、密码或升级版本号，也不改动账号和更新设置。
- 关闭、开始使用、主教程系统返回会持久化已读状态。写入异常时仍允许退出，不用教程遮住首页；以后启动可以再次提示。
- 阅读页码、子图解、图片标识和手动打开状态通过独立 SavedStateHandle 恢复。进入子图解不改变主教程页码；返回先关闭大图，再回主教程，最后关闭教程。
- 图片在后台按显示区域采样解码；分页仅组合必要页面，不一次解码 10 张原尺寸截图。大图支持手势及按钮缩放，旋转时保存缩放状态。
- 教程浮层显示期间，首页更新提醒延后。GitHub 按钮只通过 ACTION_VIEW 打开固定项目网页，不执行 Star 或账号操作。
- 首页标题及“使用教程”按钮固定在正文滚动区域之外，原账号表单、认证核心、更新下载及安装逻辑不变。
