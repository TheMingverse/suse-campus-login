升级到 1.1.3（适用于原 1.0 / 1.1.0 / 1.1.1 / 1.1.2 用户）

本次新增：学校实时上网服务列表及“刷新服务列表”。
原服务名称仍有效时继续自动登录；名称变化时请重新选择并保存，不自动猜选。
刷新只读学校信息，不提交账号密码、不解除账号错误保护，暂停时也可用。

升级步骤：
1. 右下角旧程序图标 → 右键 → 退出程序。只关窗口不算退出。
2. 将新版 ZIP 全部解压到固定位置，保留原 1.1.2 文件夹便于回退。
3. 打开新版 CampusLogin.exe，确认底部版本 1.1.3。
4. 原账号密码、运营商、开机和通知选项继续沿用，无需复制个人设置。
5. 发现学校要求认证时，自动读取最新服务列表；若提示原服务不可用，选择后保存并测试。
6. 若使用开机启动，请自行勾选“开机自动运行”并点“保存并测试”更新启动路径。

使用说明：
已在线时可能显示“当前已在线，暂无法更新服务列表”，原选择保留，不必断网或退出账号。
列表为空、获取失败、同名冲突或要求额外信息时，不盲目提交账号密码，可使用官方页面。
新服务名称保存后重启仍保留。选择框改动只有保存成功后才生效。
陌生服务获学校接受但联网复核失败时暂停重复提交，需确认服务范围。
密码仍由 Windows 在本机保护；通知开关、网线优先、多网卡隔离和 15 秒联网检测继续保留。

回到 1.1.2 或更早版本：
退出 1.1.3，打开保留的旧程序。如使用自启动，请自行保存以更新路径。
旧版只接受固定服务名称；如果新版保存了新名称，旧版可能提示重新填写，需要重新选择旧版支持的运营商并保存。
降级过程没有新增自动迁移或自动修改个人设置的步骤。旧版文件原样保留。

分享给同学：只分享整个发布 ZIP，不要分享个人设置目录。
%LOCALAPPDATA%\SUSECampusLogin 仍是原个人数据位置。
真实新服务认证、宿舍网线、教室及另一台电脑仍需现场验收，自动测试通过不等于这些场景全部实测通过。
